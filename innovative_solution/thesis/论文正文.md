# 摘要

TFT-LCD生产涉及多道工序，生产参数具有维度高、量纲不一致、缺失与冗余并存等特点。面向多工序生产数据的连续质量特性预测任务，本文构建以折内特征处理、特征分支比较和集成回归为核心的机器学习研究流程，围绕生产参数与质量特性之间的统计关系开展数据分析、模型构建与预测评价。

研究使用800条训练记录、300条测试A记录和412条测试B记录，输入包含5952个字段。首先进行字段类型识别、缺失统计与相关记录分组，在训练折内完成设备条件填充、缺失指示、类别编码和监督特征筛选，并构造工序统计与时间代理特征。将基础、基础加工序、基础加时间及组合表示分别与树深2和3组合，形成八个XGBoost候选配置，各采用三个固定随机种子的等权集成。通过嵌套时间代理窗口完成配置选择与外层评价，同时设置多类回归算法对照、特征消融及统一候选预算实验，结合关联组重采样、区间校准与逐样本残差分析呈现预测结果。

实验结果表明，在相同300条外层记录上，基础加时间特征的深度2模型MSE为0.022162，较基础特征模型的0.024533降低约9.66%；八候选嵌套选择的外层MSE为0.023242。最终开发段选用基础加工序统计、树深3的配置，使用全部训练记录拟合后，A集回顾性评价MSE为0.032528。本文通过特征与算法对照展示不同建模选择的预测表现，形成涵盖数据审计、折内处理、集成预测、误差诊断及可视化的可复现流程，并生成符合比赛格式的A/B预测文件，为TFT-LCD生产数据的质量特性估计与模型比较提供实验参考。

关键词：机器学习；TFT-LCD；质量预测；工序特征；集成学习

# Abstract

TFT-LCD production generates high-dimensional data with heterogeneous scales, missing observations, and redundant variables. This study develops a machine learning workflow for predicting continuous quality characteristics from multistage production records. The workflow combines feature processing within training folds, feature-branch comparisons, and ensemble regression to examine predictive relationships between production parameters and quality characteristics.

The dataset contains 800 training records, 300 test-A records, and 412 test-B records, with 5,952 input fields. Field identification, missingness analysis, and grouping of related records precede modeling. Tool-conditional imputation, missingness indicators, categorical encoding, and supervised feature selection are fitted within training folds, followed by process statistics and timestamp-proxy features. Four representations, comprising basic features, basic plus process statistics, basic plus timestamp proxies, and their combination, are paired with tree depths two and three. Each of the eight XGBoost candidates averages predictions across three fixed random seeds. Nested windows ordered by timestamp proxies support configuration selection and outer evaluation. Regression baselines, feature ablations, and comparisons with a uniform candidate budget are evaluated alongside group-cluster resampling, interval calibration, and sample-level residual analysis.

On the same 300 outer records, the depth-two model using basic features and timestamp proxies achieves an MSE of 0.022162, approximately 9.66% below the basic-feature MSE of 0.024533. Eight-candidate nested selection yields an outer MSE of 0.023242. Development selects basic features with process statistics and tree depth three; refitting this configuration on all training records yields a retrospective test-A MSE of 0.032528. The experiments characterize the predictive performance of alternative features and algorithms. The resulting reproducible workflow covers data auditing, feature processing, ensemble prediction, error diagnosis, visualization, and competition-format A/B prediction files, providing an experimental reference for quality-characteristic estimation and model comparison using TFT-LCD production data.

Keywords: machine learning; TFT-LCD; quality prediction; process features; ensemble learning

# 1 绪论

## 1.1 研究背景

制造过程中的质量检测能够反映产品是否满足要求，但检测结果通常需要结合生产参数才能用于分析问题来源。随着生产数据采集能力的提高，利用过程变量建立质量预测模型成为智能制造研究的一项任务。Kusiak对智能制造的研究讨论了数据与制造系统相结合的方向[1]。在这一背景下，机器学习可以通过已观测样本学习生产参数与质量特性之间的统计关系。

薄膜晶体管液晶显示器，简称TFT-LCD，是本研究的数据应用场景。赛题资料将机台、温度、气体和液体流量、功率以及制程时间等列为生产影响因素，要求根据这些输入预测连续质量特性值[2]。本文研究的是数值回归，不涉及显示图像识别。输入数据以工序编号组织，适合从单个测量字段和工序整体状态两个层面构造预测信息。

实际数据具有明显的小样本高维特点：训练记录800条，而输入字段达到5952列。直接将全部字段交给模型，会同时面对冗余变量、稀疏观测及复杂参数空间。不同设备的工作状态和记录时间也可能影响输入分布。因此，质量预测需要将数据处理、特征表示与验证设计结合起来，而不能只依赖单一模型的拟合能力。

## 1.2 研究目标与问题

本文的目标是建立从多工序生产参数到质量特性Y的回归流程，并用一致的评价样本比较不同特征表示与模型配置。研究重点包括：如何在缺失和冗余变量较多时保留有效信息；如何利用工序编码构造尺度可比较的统计特征；如何在样本有限且存在相关记录的条件下完成参数选择与评价；如何结合残差和预测区间分析模型的适用范围。

数据中的字段及目标已匿名化，因此本文将Y统一称为质量特性指标。模型学习的是观测变量与Y之间的预测关系，物理量名称、单位及质量验收界限需要结合生产字段字典确定。本研究的直接用途是离线质量特性估计与辅助分析。

本文将预测任务定义为完整记录已采集条件下的离线终点特性估计，不声称在某一中间工序提前获得预测。数据并未给出逐字段可用时点，因此无法仅依据列名排除潜在的质检后信息。删除显式时间分支用于检验对时间编码的依赖，但不能代替工厂对全部输入来源和可用时点的确认。

## 1.3 研究内容与技术路线

研究从数据结构和缺失分布分析出发，将同ID或相同输入的记录关联分组，依据时间代理构造评价窗口。每个训练折独立完成结构筛选、缺失填充与监督特征选择；在选取关键测量字段的基础上，增加工序统计和时间特征。模型采用XGBoost集成，设置特征视图与树深的组合对照，通过内层选择、外层评价和尾段校准分析形成完整实验链。

本文以特征分支是否具有增量预测价值为比较问题，将相关记录隔离、折内特征处理和结果追溯贯穿建模过程。工序统计是一项待检验的表示选择，其存在不预设性能改善。各分支使用相同外层记录，逐样本预测、模型和处理状态共同支持结果核查。

本文的贡献属于应用与实验方法层面：在匿名工序结构下实现可插拔的特征表示，并用算法对照、消融、关联组推断和条件覆盖共同评估其作用。树学习算法、集成平均和重采样方法均采用已有技术，本文不将技术组合本身表述为新的基础算法。

# 2 相关研究与方法基础

## 2.1 制造质量预测研究

制造质量预测将可采集的生产变量作为输入，将质量测量值作为监督信号。其建模难点不仅取决于预测算法，也与传感器数据的完整性、工序之间的信息冗余和训练样本的代表性有关。对于匿名竞赛数据，研究通常需要先识别字段结构，再评估特征表示与学习器之间的适配关系。

屈方磊的研究使用TFT-LCD质量预测数据，将GBR、XGBoost、随机森林和支持向量回归用于集成建模，并结合特征筛选开展质量特性预测实验[3]。该研究为同类数据的建模提供了参考。本文围绕工序表示、相关记录隔离和时间窗口验证组织实验，不对不同文献中采用不同划分得到的误差直接排序。

## 2.2 树模型与集成学习

梯度提升通过逐步增加基学习器优化损失函数。Friedman将其描述为函数空间中的梯度优化过程[4]。在平方损失下，负梯度与残差成比例，后续学习器能够逐步修正已有预测的误差。XGBoost在树模型目标中加入正则化，并采用高效的训练实现[5]。树的深度、叶节点约束和采样比例共同影响模型复杂度。

随机森林利用样本与特征随机性训练多棵树，再将预测平均[6]。ExtraTrees进一步对切分阈值引入随机性[7]。这类方法能够表示非线性关系，并为变量筛选提供重要性分数。本文以ExtraTrees作为特征筛选器，以XGBoost作为质量预测器，使变量压缩与最终回归承担不同任务。

LightGBM研究了高效梯度提升树训练中的采样与特征组织方法[8]；CatBoost研究了有序提升和类别变量处理[9]。本文将两者与岭回归、随机森林、GBR和SVR共同纳入算法对照。为统一输入，所有对照使用相同的折内数值化特征，CatBoost未使用原生类别特征输入，因此结果评价的是这一统一表示下的实现。

集成预测既可以采用等权平均，也可以学习组合权重。Stacking利用基学习器预测训练第二层模型[10]。组合参数越多，所需的选择与验证数据也越多。考虑到样本规模，本文采用三个预设随机种子的XGBoost等权平均。每个成员分别拟合特征处理器，以反映采样、特征筛选和模型训练中的随机性。

## 2.3 高维数据与特征表示

岭回归通过L2惩罚缓解相关输入下的参数不稳定[11]，反映了高维建模中控制复杂度的重要性。特征选择与降维是两类不同手段：特征选择保留输入字段，便于定位工序来源；降维将多个字段映射为较少的潜在分量，能够压缩输入，但会改变特征的解释方式。

PCA按输入方差构造主成分，SVD利用矩阵低秩结构进行压缩，PLS则在降维时利用目标信息。方差表示变量的离散程度，并不等同于对质量特性Y的贡献；累计解释方差也不等同于累计预测贡献。项目按填充、尺度变换、降维、预测的顺序保留可插拔接口，所有拟合限定在训练折。主实验采用可追溯字段表示，不以不同评价样本上的降维分数进行排名。

Grinsztajn等比较了典型表格数据上的树模型与深度模型，讨论了树模型在中等规模表格任务中的表现[12]。Hollmann等提出表格基础模型并报告了小样本基准结果[13]。这些研究表明表格预测可以采用多种技术路线。本文实验集中于树模型和工序特征表示，表格基础模型作为后续扩展方向。

## 2.4 缺失数据与预测评价

缺失数据处理需要区分观测值本身与缺失过程携带的信息[14]。在制造场景中，缺失可能与测量频率、设备状态或数据采集过程有关。本文采用设备条件统计填充，同时增加缺失指示，使模型能够利用观测模式。由于缺少完整采集日志，具体缺失机制保留为待确认因素。

生产数据还可能随时间或设备条件发生变化。概念漂移研究关注数据生成关系的变化及模型适应问题[15]；仅有输入均值或缺失率差异，仍不足以判定输入与目标的条件关系已经改变。时间外推评价关注模型在后续观测上的误差[16]，因而需要明确排序依据及每次评价可使用的数据范围。

点预测只给出一个估计值，预测区间则进一步表示误差范围。拆分共形预测利用校准残差构造区间，其覆盖论证依赖交换性等条件[17]。本文采用单独校准段计算残差分位数，并在尾段报告经验覆盖率。由于生产记录可能存在时间依赖，实际覆盖率是本研究的评价对象，不直接视为未知样本上的保证。

## 3.2 缺失分布与数据清理

缺失分析同时从字段和记录两个方向进行。字段缺失率反映测量信息的完整程度，记录缺失率反映单个样本可用信息的多少。训练集5952个输入字段共包含4761600个单元格，其中213525个缺失，单元缺失率为4.484%。有227列全空，因此800条训练记录均存在至少一个缺失字段。

数据结构统计识别到717个常量字段、2305个重复字段和72个可解析时间字段。按描述性清理口径得到的2617个普通数值字段中，609条记录含缺失，单元缺失率为0.834%。表3-2同时列出两种统计范围，说明缺失率必须与所使用的字段分母对应。描述性清理用于理解数据，模型实际使用的字段集合则由各训练折独立确定。

表3-2 不同字段范围的缺失统计

| 统计范围 | 字段数 | 含缺失记录数 | 单元缺失率 | 最大记录缺失率 |
|---|---:|---:|---:|---:|
| 全部输入字段 | 5952 | 800 | 4.484% | 12.920% |
| 结构清理后数值字段 | 2617 | 609 | 0.834% | 13.107% |

NH1463在全部输入字段中缺失769项，在结构清理后的数值字段中缺失343项。虽然第二个缺失数量更少，但由于分母减少，其比例反而更高。此类样本保留在实验中，通过填充、缺失指示及误差分析考察模型表现。

分布诊断结合分位数、偏度和理论分布拟合距离描述测量值的集中与偏离情况。理论分布的参数由数据估计时，普通固定分布KS检验的p值不能直接用于判断拟合成立；拟合距离在本研究中作为描述性信息。树模型并不要求输入服从正态分布，因此分布分析主要服务于异常范围检查与特征变换选择。

## 3.3 相关记录与时间分布

训练集中35组ID各出现两次，同组目标值相同，而部分输入存在差异。本文以同ID或完全相同输入建立关联分组，共得到765个验证组。同组记录全部保留；当组跨越训练与验证边界时，移除训练侧的相关记录，以避免评价时出现已见过的关联实体。该规则采用保守的记录身份假设，业务含义仍需产品追溯信息确认。

时间排序采用72个可解析时间字段的行中位数作为代理。按这一代理，训练集覆盖2017年6月15日至7月23日，A集覆盖5月30日至7月22日，B集覆盖6月5日至6月19日。A集250条、B集373条早于训练集最早代理时间，A文件行序与代理时间的Spearman相关约为0.084。这说明竞赛文件的公开顺序与记录的生产时间代理并不一致。

![图3-1 数据集时间代理分布](audit_01_time_proxy_ranges.png)

时间窗口评价在训练集内部按代理时间排序进行，同时排除时间相等或倒置的训练边界记录。由于代理由匿名字段构成，本文将其作为统一的排序依据。若用于工序中途预测，还需要按照真实测量可用时点重新约束输入范围。

对训练集、A与B的两两组合分别检查ID与全部输入严格相等关系，三个组合均为零重叠。该结果排除了已记录身份与完全重复输入的跨文件重用，不能排除未标识的同批次关联。时间代理采用最小值或最大值时，与中位数代理的Spearman相关分别约0.959和0.948，但尾段100条记录的交集分别只有81和61条，表明排序口径会影响评价样本。

## 3.4 折内预处理

预处理依次执行非有限值转换、字段结构筛选、数值填充和类别编码。全空字段被排除，无缺失且仅有单一取值的字段被识别为常量；常量值伴随缺失时保留其观测模式。完全重复的输入字段只保留一份。所有结构判断都在当前训练部分进行，验证记录仅使用已经拟合的处理器转换。

设备条件填充先在训练部分计算同设备组的字段均值，缺失时使用该组均值；对于未见设备或缺乏有效组统计的字段，以训练中位数兜底。设备与工序的对应关系依据字段命名和列位置解析，属于可重复实现的分组规则。对于训练缺失率至少0.5%的入选字段，额外生成缺失指示。

设备组均值的支持数按“设备与字段”的非缺失观测计数，不能仅用设备组总行数替代。实验分别考察至少1个有效观测、至少5个有效观测，以及至少5个并向训练中位数收缩的三种策略。收缩估计为组观测和加10倍训练中位数，再除以有效观测数加10；支持不足时直接回退训练中位数。若某组只有一条记录且该字段缺失，其有效观测数为零，并不会从该缺失值本身构造均值。

类别变量采用One-Hot编码。验证或测试中出现未见类别时，编码器采用安全转换规则，以保持字段顺序和维度一致。设备编号的数值大小不被当作距离关系。填充值表示训练数据给出的估计，其作用是形成可计算的输入，而不是还原缺失时的真实测量。

## 3.5 稳健工序特征

由于输入量纲不同，跨字段聚合前先进行稳健标准化。在填充后的训练数据上计算各字段中位数m和四分位距s，s为0时取1作为兜底尺度。式3-1将标准化值截断至[-8,8]，减少极大数值对工序统计的支配。i表示记录，j表示字段。

$$robust$$

对同工序编码下的标准化字段计算均值、标准差、分位数、极差和绝对值超过3的比例，并在未填充观测中统计缺失和零值。单字段表示保留局部测量差异，工序聚合则表示一组变量的整体水平与离散程度。标准化和截断只用于工序统计分支，输入树模型的基础测量字段保持自身数值尺度。

时间分支计算同工序字段的最小值、最大值、中位数和跨度，以及按工序编码排序后的相邻时间差。其含义是数据中的时间代理统计；获得真实工艺路线后，可进一步核对这些统计与加工持续时间或工序间隔的对应关系。

用于窗口排序的代理与输入模型的时间分支需分别理解：前者是72个可解析时间字段的逐记录中位数，后者包含工序内时间统计与路线代理差，并非仅输入一个行中位数。可解析只说明数值符合日期形式，不说明其代表开工、完工或质检事件。

## 3.6 特征筛选与表示方式

特征筛选综合考虑ExtraTrees重要性、与Y的绝对相关程度及训练前后两半的变化幅度。筛选器使用250棵树、最小叶节点样本数2和平方根特征采样。式3-2中的rI和rC分别为重要性与绝对相关性的百分位排名；d为前后两半中位数绝对差除以IQR，并截断至[0,20]。

$$score$$

按综合得分保留至多320个测量字段。0.70、0.30和0.25为固定工程系数，用于在贡献、关联与变化幅度之间形成可复现的排序。排名反映当前训练数据下的筛选偏好，其效果由外层预测评价检验。

实验设置四种特征表示。基础特征由筛选后的测量值、缺失指示和设备类别组成；基础加工序统计仅增加工序聚合；基础加时间特征增加时间统计与相邻工序时间代理差；组合特征同时包含两类分支。“组合”仅描述字段组成，不表示效果最好。四种表示共享折内测量字段筛选规则与集成成员数，分别检验工序统计、时间信息及二者组合的增量作用。

# 4 预测模型与实验设计

## 4.1 评价指标

点预测主要采用均方误差MSE，辅助报告均方根误差RMSE、平均绝对误差MAE和决定系数R²。MSE对大误差给予较高权重，能够反映少数严重失配对整体预测的影响；MAE用于补充展示典型误差幅度。各指标在同一组拼接预测记录上计算。

$$metrics$$

式中n为评价记录数，y为实际值，带帽y为预测值。RMSE等于MSE的平方根；MAE为绝对误差的平均；R²为1减去残差平方和与相对评价集均值的总平方和之比。本文按记录计分，同一关联组中的多条验证记录仍分别计入指标。

模型差异以同一记录上的配对平方误差差值分析。300条外层记录包含296个关联组，重采样时以整组为单位抽取并保留组内全部记录，执行5000次bootstrap，同时报告记录加权与组等权结果。组级符号翻转检验以误差差值的对称性为条件；按时间代理排列的组块长5、10、20用于相关性敏感性分析。

本文将表5-3a所列11个不同的特征与选择策略比较作为一个Holm校正族，重复实现的同一基础与组合比较不重复计数。每项同时报告参考减候选的MSE差、个别95%区间、原始p值和校正p值。该校正族不覆盖所有算法、参数搜索或研究历史，个别区间也不是同时置信区间。由于配置设计已受到数据分析影响，推断仅描述现有预测上的差异，不能作为独立确认性检验。

## 4.2 嵌套窗口与数据用途

实验将800条训练记录按时间代理稳定排序。外层设置三个扩展窗口，分别以前320、420和520条为训练候选范围，评价随后100条记录。每个外层训练部分内设置两个验证长度为60条的扩展窗口，用于选择特征表示和树深。实体与时间边界隔离会使实际训练数量略少于名义范围。

每个内层训练部分重新拟合结构筛选、填充、编码、工序尺度和监督筛选，再训练相应候选模型。根据两个内层验证段拼接后的MSE选择配置，随后用外层训练部分拟合该配置并预测外层记录。外层得分因此包含特征处理和参数选择全过程的影响。

算法对照在同一外层窗口中选择参数。岭回归比较正则系数10、100和1000；随机森林使用300棵树并比较最小叶样本2和5；GBR使用500轮、学习率0.03并比较深度2和3；SVR使用标准化RBF输入、ε为0.05并比较C为1和10。LightGBM使用800轮、学习率0.03并比较叶数7和15；CatBoost使用800轮、学习率0.03并比较深度4和6；XGBoost比较深度2和3。内层统一使用种子42，外层采用三个种子的预测平均。

为检查候选范围和轮数预算的影响，另设置统一候选预算比较。每类算法仅比较基础与基础加时间两个输入候选，其余参数固定；所有树模型使用500棵树或500轮提升，内层种子42，外层仍为三个种子。固定参数为岭回归α=100、随机森林最小叶样本2、GBR深度2、SVR的C=1、LightGBM叶数7、CatBoost深度4和XGBoost深度2。该比较统一候选数、评价窗口、随机种子数及树轮数，并记录实际耗时；不同算法的单轮计算量、容量和收敛状态仍不同，因此不称为严格相同计算预算。

此外，各特征与深度固定配置及训练均值基线在相同外层记录上评价。固定配置用于比较输入表示，嵌套选择用于评价选择规则。算法对照统一采用组合表示，其排名只比较这一输入条件下的学习器，不覆盖全部特征与算法的联合配置空间。

## 4.3 XGBoost集成与参数设置

预测器使用平方误差目标、1200轮迭代和0.05学习率。最小子节点权重为3，样本采样比例为0.8，特征采样比例为0.55，L1和L2正则系数分别为0.01和2。主搜索范围为四种特征表示与树深2或3的组合，共八个候选。代码中的raw、process、time和full分别表示基础、基础加工序、基础加时间和组合表示，d2与d3表示树深。

另以仅含基础和组合表示的四候选搜索作为候选范围对照。八候选范围受到同一数据上分支消融结果的启发，虽在计算前保存协议，仍不能消除研究设计层面的适应性选择偏差。两种搜索保留完全相同的窗口索引；八候选的所有内层分数均保存，最终配置只由开发段内层MSE决定。

每个候选使用随机种子42、143和244训练三个成员，并按式4-2等权平均。成员之间分别学习特征筛选和模型参数，其预测差异来源于训练过程的随机性。平均预测用于降低对单次随机训练的依赖；三个成员仍共享同一批观测，统计推断的样本单位仍为评价记录。

式中x为处理后的特征向量，f_s为第s个成员的回归函数，带帽y为三个函数输出的算术平均。算法对照采用单个内层种子控制计算预算，特征配置主实验则在内层也采用三个种子，二者的选择结果分别记录，不合并解释为同一搜索预算。

$$ensemble$$

固定对照使用深度2和相同的三成员预算。组合特征模型与基础特征模型的差别在输入表示，其他训练参数保持一致。最终用于生成A/B点预测的配置由开发段内层评价决定，而不是根据外层结果再次选择。

## 4.4 预测区间构建

区间评估采用模型开发、校准与尾段评价三种用途。模型在前段选参后，以620条记录拟合并冻结；在80条校准记录上计算绝对残差；随后对100条尾段记录产生点预测和区间。区间以点预测为中心，以校准残差的上分位次序统计量作为半径。

$$interval$$

式中m为校准样本数，α取0.1，r(k)为校准绝对残差排序后的第k项。本实验m=80，使用第73个绝对残差。若k超过m，则将半径定义为正无穷，表示校准样本不足以支持该有限分位界限。

区间评价同时考虑覆盖率和宽度。覆盖率为实际值位于区间内的记录比例，宽度衡量预测范围的紧密程度。时间依赖可能使校准残差与尾段误差不同，因此以实测覆盖报告区间表现。A/B模型使用更多标签重新拟合后，其误差分布也可能变化，故对应提交文件仅输出点预测。

## 4.5 实验实施与结果保存

实验环境使用NumPy 2.3.5、pandas 2.3.3、scikit-learn 1.7.2和XGBoost 3.4.0。运行配置、候选集合和随机种子与实验结果一起保存。输入文件通过SHA256校验，Excel与缓存的列名、行序及全部单元格已进行一致性核验。

每次切分保存训练与验证索引、关联组交集和时间边界；每个预测器保存完整预处理状态、字段顺序及模型参数。逐样本结果包括ID、实际值、预测值和所属评价窗口。该组织方式将汇总指标与具体记录连接起来，便于追踪高误差样本及复现数据转换。

对于A集，点预测模型使用800条训练标签拟合，公开A标签用于回顾性评价。A标签也参与了本研究的探索性分析，因此A结果不作为独立盲测。B集预测在允许使用公开A标签的条件下，将800条训练记录与300条A记录等权合并，拟合相同选定配置。

## 5.5 时间方向与输入可用性

在同一组300条评价记录上，以较晚记录训练并预测较早记录时，基础特征和组合特征MSE分别为0.028100和0.027704。反向回放改变了训练样本范围和数量，仅用于检查时间方向敏感性，不能将与前向回放的差值单独归因于漂移。A/B分布与前向窗口并不完全一致，因此前向分数不直接估计竞赛测试误差。

工序统计分支可在不输入显式时间特征时运行，因而能够检验模型对时间编码的依赖。匿名的非时间字段仍可能在目标测量后才生成，移除时间分支不构成“所有输入均无泄漏”的证明。本文的实证范围是已采集完整记录上的离线关联预测，工序中途可用性需要生产日志进一步核实。

逐字段清点覆盖全部5952个输入，记录字段类型、工序编码、物理含义、来源系统、采集事件、最早可用时点及其是否早于Y测量。由于缺少字段字典和事件日志，5952项的目标测量前可用性均未核实，可核实允许进入前瞻模型的字段数为0。这表示证据不足，并不表示所有字段都已被证明泄漏。输入清点已完成，物理可用性核实仍未完成。

A集250/300、B集373/412条记录的代理早于训练范围下界，两集均无晚于训练范围上界的记录。用全部训练标签拟合A/B，因此属于按匿名代理跨范围的离线回顾性估计；不能把它描述为真实生产中从过去预测未来。外层按代理顺向回放评价一种划分下的泛化，无法直接代表A/B的方向与分布。即使删除时间输入，排序代理和未核实的非时间字段仍保留这些限制。

时间信息可能反映批次变化、设备变化、记录制度或质检后事件，现有资料无法区分。只有取得字段事件含义、Y测量事件及实际决策时点后，才能形成可用字段清单，并在新增周期上重建面向该时点的预测评价。本文不把统计增益转述为提前预警或质量控制收益。

使用全部800条训练记录拟合的模型在A集上的MSE为0.032528、RMSE为0.180356、MAE为0.147124、R²为0.411128。A集时间代理与训练集存在较大范围差异，该分数描述模型在公开A记录上的表现。结合第4.5节所述标签用途，该评价属于回顾性结果。

B集通过1100条已知标签等权训练的模型生成412条预测。测试B没有可用真实标签，因此本研究提供其点预测结果及生成过程，不计算B误差。A/B输出均为两列无表头CSV，第一列保留测试文件ID与行序，第二列为预测Y。重复ID按记录原样保留，以确保与比赛文件逐行对应。

公开A答案的存在不等同于已确认所有竞赛阶段的训练许可。本文把合并标签的B模型作为增量学习实验，同时保留仅训练集标签拟合的B文件。当前访问的竞赛规则页面未提供可核实的完整条款，因此不声称完成线上规则审查或官方成绩验证。

## 5.9 应用范围与实验局限

基础特征保留测量层面的细节，工序统计表示变量的整体水平与离散程度，时间分支表示匿名时间结构。固定深度2下，基础加时间优于同时加入两个分支的组合表示；工序统计的单独增益区间跨零。本文据此报告工序聚合未得到稳定增益支持的结果，不能由字段数增加推断信息价值增加。

模型重要性可将输入字段按工序编码汇总，为进一步检查提供候选范围。树模型中的重要性反映变量参与预测分裂的贡献，可能受到相关变量和重复信息的影响。实际问题溯源需要结合设备日志、测量单位及工艺知识，核对高重要性变量是否在预测时点可用，以及其变化是否具有明确生产含义。

选定的基础加工序统计 深度3三成员模型在本机的单记录预测中位耗时为3.812秒，100条批量预测为3.997秒，包含输入驻留内存时的特征转换与模型计算。测试不包含生产采集、网络、排队和质检反馈时间，不能据此承诺产线实时性。

实验使用一个匿名数据集，样本数量与可用时间范围有限。同ID记录通过保守规则隔离，真实产品键和批次结构仍需确认。时间代理由多个匿名时间字段构造，其排序可以用于统一回放，但真实开工、完工和质检时间的对应关系尚未完整验证。

三个外层窗口提供了同样本比较，样本之间的相关性仍限制统计推断。缺少Y单位、测量误差、质量上下限和误判成本，无法判断约0.00275的RMSE绝对差异是否具有实际工艺价值。现有R²和离线时延可以描述模型行为，但不足以量化良率改善、检测节约或自动放行收益。

# 6 结论与展望

## 6.1 研究结论

本文围绕TFT-LCD多工序质量特性预测，完成了数据分析、折内预处理、工序特征构造、集成回归、嵌套评价与逐样本诊断。设备条件填充和缺失指示形成可计算的输入表示，稳健工序统计与时间代理在测量字段之外提供补充信息，相关记录隔离与折内拟合明确了实验的数据边界。

在300条外层评价记录上，基础加时间的深度2模型MSE为0.022162，低于组合表示0.023679和基础表示0.024533。工序统计未显示稳定的增量改善，不能把组合表示相对基础表示的差异全部归因于工序聚合。时间分支在本数据上较有预测信息，但其物理含义与预测时点可用性尚需验证。

八候选嵌套选择的外层MSE为0.023242，开发段内层选定process_d3，其冻结尾段MSE为0.044408、固定区间覆盖率为87%，公开A集回顾性MSE为0.032528。候选扩展受同一数据上的结果启发，仍不能替代独立确认。本文定位为匿名制造数据上的方法比较与适用边界分析，主要发现包括时间分支的相对优势、工序统计缺乏稳定增益以及有限样本配置选择的限制。

研究输出完整模型与预处理器、窗口索引、配置及逐样本预测，并生成符合比赛格式的A/B结果文件。该流程可作为匿名制造数据质量回归研究的实现基础，为进一步获取工艺语义和开展现场评价提供准备。

## 6.2 后续研究方向

首先，应补充真实产品键、设备批次、字段单位与测量可用时点，使工序表示能够对应实际生产流程。在明确预测时点后，按信息可用性构造输入，使用新增生产周期开展前瞻评价。

其次，应在新增独立数据上复核算法和消融结果，而不是继续在同一组验证记录上扩大搜索。降维、深度模型或表格基础模型应在相同样本与参数预算下评价。对于少数低Y样本，应结合检测记录判断其代表性，再研究局部建模或分位数预测，避免仅根据误差反复加权。

最后，区间方法需要同时关注覆盖、宽度和时间变化，可进一步研究滚动校准和按设备条件分层评价。面向生产应用时，还应结合质量上下限、误判成本与实际推理时延评估使用方式，使离线预测结果与人工复核及质量管理流程衔接。
